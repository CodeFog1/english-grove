# English Grove

A simple English learning website with vocabulary practice, reading cards, and easy English news examples.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example, `english-grove`).
2. Upload `index.html` and `.nojekyll` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
5. Save and wait for GitHub Pages to publish the site.

The article and news items in this prototype are sample content, not live news.
